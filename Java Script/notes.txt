DataTypes :
===========
    ->DataTypes represent the what type of data we are storing on that variable

    Types : 
        1.Primitive
            i. number
            ii. string
            iii. boolean
            iv. null
            v. undefined
            vi. symbol
            vii. bigint
        2.Non Primitive
            i.Arrays
                ->Arrays are the linear data structures used to store collection of homogeneous or heterogeneous data
                In JS Array Declaration :
                =========================
                    1. Literal way
                    2. Using new keyword (object)
                
                Loops :
                =======
                    1. for loop
                    2. while loop
                    3. do while loop
                    4. for-of loop (arrays/strings) -> only values
                    5. for-in loop (arrays/strings) -> only index's
                    6. forEach loop

                    7. map()
                    8. filter()
                    9. reduce()

            ii. Objects
                -> Objects are the real time entities in used to store data in the form of key and value pair

                In JS Objects Declaration :
                ===========================
                    1. Literal way
                        Syntax :
                            variableType varableName = ({
                                key1:value,
                                key2:value
                            });
                    2. Object way
                        Syntax :
                            variableType varableName = new Object({
                                key1:value,
                                key2:value
                            });
            iii. Functions
                -> functions are the block of statements which will get execute when ever it is called

                Notes :
                    -> Using functions we can perform Code reusability
                    -> And also increase Code reusability

                Types :
                =======
                    1. User Defined Functions
                    2. Built In Functions / Pre Defined Functions

    In JS we can Declare functions in many ways(classifications) :
    ==============================================================
        1. Anonymous function
        2. normal/named function
        3. functional function
        4. first lass function
        5. immediate invoking function / self calling function
        6. arrow function (ES6)
        7. nested functions
        8. higher order function
        9. callback function
        10. generator function
