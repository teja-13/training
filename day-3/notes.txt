Lists in HTML:
==============

    Types :
        1.Ordered List
            -> <ol> </ol> represent the ordered list 
            -> It contains list of items
            
            Attributes:
            ===========
                1.start -> numbers
                2.type ->1,a,A,i,I
                3.reversed

        2.Unordered List
            -> <ul> </ul> represents the unordered list
            
            Attributes:
            ===========
                1.Type -> none, disc, circle, square

        3.Description / Definition List
            -> <dl> </dl> -> represents the description list
            -> <dt> </dt> -> represents the description term
            -> <dd> </dd> -> represents the description data

        4.Nested List
            ->A list inside another list is called a nested list
